# v0 project plan

The deliverable is a reviewed Nature of Use paragraph backed by separate rights findings, not rate or clearance automation.

| Milestone | Implementation |
|---|---|
| 1 · Foundation | Python package, strict schemas, historical ingestion/audit, safe local configuration |
| 2 · Measurement | Experimental PF-NMF, synthetic fixtures, optional CPU SampleID adapter, temporal grouping and direct-waveform patch refinement |
| 3 · Rights analysis | Independent publishing/master results; explicit unsupported and uncertain states |
| 4 · Synthesis | Deterministic evidence-first draft; separate historical references and expert corrections |
| 5 · Application/evaluation | Four Streamlit views, playback/timelines, review/export, reserved-case evaluation harness |

Required validation: synthetic numerical tests, rights isolation, leakage prevention, review/export invariants and actual Streamlit interaction. Optional validation: checkpoint-backed SampleID inference and historical scoring when their prerequisites are available.

Next milestone: supply the client PF-NMF implementation/findings and rights-authorized paired audio; compare this baseline with the supplied method on development cases. Confirm reserved labels with the expert before evaluating. Establish a review rubric and collect real correction/review times before claiming time savings. Build automatic section/composition localization only after validating intermediate evidence quality.
